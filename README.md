# 🛒 PrimeMart Retail Dashboard

📌 **Project Overview**
An end-to-end retail data analysis project for **PrimeMart Retail** using Python and Power BI to uncover sales trends, profit margins, and regional performance across West, East, Central, and South regions.

🛠️ **Tools & Technologies**
* **Python (Pandas):** Data cleaning and null handling.
* **Power BI:** Data modeling, DAX measures, and interactive dashboards.

📊 **Key Pages & Findings**
* **Sales Performance:** Tracks total sales ($2.30M), total orders (5.009K), ship modes, and regional distribution.
* **Profit & Products:** Analyzes total profit ($286.40K), profit margins (12.47%), product categories, and top customers/products.
